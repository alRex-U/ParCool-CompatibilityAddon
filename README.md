# ParCool+ / Compatibility Addon

This is an addon of [ParCool](https://www.curseforge.com/minecraft/mc-mods/parcool) for adding compatibility with other
mod.

---

## Supported Mods

- Better Combat
  - fix animation issues
- Carry On
  - stop ParCool actions while carrying
- First Person Model
  - enable FPV animation of ParCool automatically while First Person Model is active
- Paraglider
  - fix animation issues
- Player Animator
  - prioritize its animation than some ones of ParCool
- RealCamera
  - adjust camera and animations to make its view naturally
- Timeless and Classics Zero
  - fix animation issues
